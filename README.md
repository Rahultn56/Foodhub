# 🍔 Foodie (Foodhub) - Online Food Ordering System

A fast, responsive online food delivery and ordering web application. Browse top restaurants, explore categorized menus, search favourite dishes, manage cart with live price calculation, and place orders with instant confirmation.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FRahultn56%2FFoodhub)

---

## 🌟 Key Features
- **Featured Restaurants**: Browse popular cuisines — Pizza Palace 🍕, Burger House 🍔, and Royal Biryani 🍛.
- **Dynamic Menu Discovery**: Restaurant-specific menus with high-resolution food imagery, item descriptions, and pricing in ₹ (INR).
- **Instant Search**: Real-time fuzzy food search filter across all dishes.
- **Interactive Cart**:
  - Add / remove dishes with live quantity controls (+ / -).
  - Dynamic cart badge counter.
  - Automatic subtotal and grand total calculation.
- **Order Placement Modal**: Animated order success modal with status messaging.
- **Responsive Layout**: Designed for seamless browsing across mobile, tablet, and desktop viewports.
- **100% Vercel Ready**: Preconfigured with `vercel.json` for zero-config global edge deployment.
